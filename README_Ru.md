# Clear-Text («Ясный Текст»)

> 🌐 **Язык:** [English (README.md)](README.md) | **Русский**

AI Telegram-бот помощник для слабовидящих и пожилых людей, которым трудно читать мелкий шрифт на упаковках лекарств, медицинских инструкциях или квитанциях.

## ✨ Возможности
- 📸 **Распознавание и упрощение по фото** — использует мультимодальную модель **Google Gemini** для анализа фотографий упаковок и документов.
- 🚨 **Встроенный SOS-Детектор** — автоматически проверяет инструкцию или упаковку на критические опасности (просроченный срок годности, строгие противопоказания, ядовитые вещества, пометки «строго по рецепту» или «опасно при беременности/детям») и выводит предупреждение первым пунктом.
- 📋 **Понятная структура** — переводит сложные медицинские и юридические формулировки на простой и краткий язык без «воды».
- 🔊 **Голосовая озвучка (TTS)** — синтезирует чистую русскую речь (`edge-tts`, голос `ru-RU-DmitryNeural`) и отправляет голосовое сообщение в ответ.

## 🚀 Установка и запуск

1. Установите зависимости:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
2. Создайте файл `.env` на основе `.env.example` и укажите ваши ключи:
   ```bash
   cp .env.example .env
   ```
3. Запустите бота:
   ```bash
   python3 bot.py
   ```
